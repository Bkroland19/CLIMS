# CLIMS 2.3.0

- Implements identity-sync contract 1.1 for MoH SSO: account links, session revocation, and a test probe that the backend refuses to start with in production. See the [SSO and identity sync guide](../sso-and-identity-sync.md).
- Adds delivery agents for hotspot deliveries, an optional agent when dispatching, and a field-app notifications inbox with push through Firebase Cloud Messaging.
- Adds one page per hotspot stockout request, where the DCFP can supply it or reject it with a reason that the field app shows.
- Shows the live audit log on the web, with filters by action domain.

## Upgrade from 2.2.1

Back up PostgreSQL before deploying. The backend applies migrations 000035 through 000038 at startup.

New optional settings in `infra/env/prod.env` (see `infra/env/prod.env.example`):

- `OIDC_ISSUER`, `OIDC_CLIENT_ID`, `OIDC_CLIENT_SECRET`, `OIDC_PUBLIC_ORIGIN`, `IDENTITY_SYNC_CLIENT_ID` for portal sign-in through MoH Keycloak. Leave `OIDC_CLIENT_ID` blank for password sign-in only.
- `APP_ENV=production` (the default when unset). Do not set `IDENTITY_SYNC_TEST_PROBE` in production.
- `FIREBASE_CREDENTIALS_JSON` for push notifications. Empty disables push; notifications still reach the in-app inbox.
