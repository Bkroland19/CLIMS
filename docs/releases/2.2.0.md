# CLIMS 2.2.0

- Adds inventory movements and reporting, with frontend workflows for deliveries, stock adjustments, and stock checks.
- Adds MoH SSO integration and OIDC identity linking. See the [SSO configuration guide](../../infra/sso/README.md).
- Updates the frontend and adds end-to-end coverage for hotspot activation, logout, and session refresh.

## Upgrade from 2.1.0

Back up PostgreSQL before deploying. The backend applies migrations 13 and 14 at startup to add inventory movements and OIDC identity records. The OIDC migration uses version 14 so it can run alongside inventory migration 13.

See the [release guide](../releases.md) for digest-pinned application images and deployment details.
